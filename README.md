💰 Expense Tracker

🧾 A Python-Based Personal Expense Management System

«📊 A simple and user-friendly application to record, manage, and analyze daily expenses.»

---

📌 Project Overview

Expense Tracker is a Python-based application designed to help users manage their daily expenses efficiently.

The application allows users to:

- ➕ Add new expenses
- 👀 View all recorded expenses
- 💵 Calculate total expenses
- 📊 Analyze expenses by category
- 🔎 Search expenses by category
- 💾 Store expense data permanently

The project demonstrates the practical use of Python programming concepts, file handling, CSV processing, functions, loops, conditions, lists, and dictionaries.

✨ Features

➕ Add Expense

Users can enter:

- 📅 Date
- 🏷️ Category
- 💰 Amount
- 📝 Description

👀 View Expenses

Displays all recorded expenses in an organized format.

💵 Calculate Total

Calculates the total amount spent across all recorded expenses.

📊 Category Summary

Groups expenses according to categories and calculates the total spent in each category.

🔎 Search by Category

Allows users to find expenses based on a particular category.

💾 Permanent Storage

Expense information is stored in a CSV file so that the data remains available after closing the application.
